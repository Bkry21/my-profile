# موقع بكري — بورتفوليو

موقع بورتفوليو مبني بـ Next.js + TypeScript + Tailwind CSS، بتصميم عربي (RTL)
بأسلوب "دفتر أعمال" (ledger) يعكس طبيعة الأنظمة التي تُبنى: مندوبي،
الصيدليات، تأجير البدل، وغيرها.

## التشغيل محلياً

```
npm install
npm run dev
```
يفتح على http://localhost:3000

## البناء للنشر

```
npm run build
npm start
```

## قبل النشر — لازم تعدّل
- رقم واتساب في src/app/page.tsx (ابحث عن wa.me/249000000000)
- البريد الإلكتروني (ابحث عن hello@example.com)
- المحتوى/المشاريع في مصفوفة projects داخل src/app/page.tsx لو حابب تضيف أو تعدّل

## النشر
أسهل طريقة: ارفع المجلد على Vercel (vercel.com) — استضافة مجانية للمشاريع الشخصية.
